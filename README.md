## 🚀 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/walls.git
   ```
2. **Browse the `collection/` folder** and set your favorite image as your wallpaper!

## 🤝 Contributing

Contributions are welcome! If you have a wallpaper you'd like to share:
1. Fork the repository.
2. Add your image to the `collection/` directory.
3. Update the README if necessary.
4. Create a Pull Request.
